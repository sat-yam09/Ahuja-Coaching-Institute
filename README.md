# Ahuja Career Institute

A modern, high-performance web platform for **Ahuja Career Institute**, built with **Next.js 15**, **React 19**, **TypeScript**, and **Tailwind CSS**.

---

## 🌟 Overview

Ahuja Career Institute has been a premier competitive coaching institute since 1998/2001, providing comprehensive preparation for:
- **JEE Main & Advanced**
- **NEET Medical Entrance**
- **CBSE & GSEB Board Foundations (Class 8–12)**

This platform delivers an immersive, dynamic user experience with interactive course explorations, demo batch bookings, faculty profiles, achievement leaderboards, syllabus downloads, and campus gallery showcases.

---

## 🚀 Key Features

- **Dynamic Hero & Admissions Ticker**: Real-time historical result ticker with top scorers and instant demo batch registration.
- **Curriculum & Course Finder**: Detailed breakdown of JEE, NEET, Foundation, and Crash Course programs.
- **Interactive Syllabus Modals**: Subject-by-subject unit curriculum details with instant demo booking triggers.
- **Faculty Directory & Mentorship Modals**: Comprehensive credentials, qualifications, and direct mentorship booking.
- **Rankers Scoreboard**: Filterable historical ranker cards by exam, year, and AIR with percentile badges.
- **Campus Gallery**: Responsive media showcase with full-screen lightbox inspection.
- **Responsive Navigation**: Mobile drawer menu, sticky announcement bars, and quick inquiry modals.

## 📦 Getting Started

### 1. Prerequisites

Ensure you have **Node.js** (v18.18+ or v20+) installed.

### 2. Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/converge-digitals/Ahuja-Institute.git
cd Ahuja-Institute
npm install
```

### 3. Development Server

Start the local development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Production Build

Build and run for production:

```bash
npm run build
npm run start
```
